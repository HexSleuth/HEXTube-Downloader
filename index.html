How this works: 100% client-side — no server, no backend. You point the app at one Piped or Invidious API instance that sends CORS headers, and it returns proxied stream URLs that the browser can fetch. Muxed MP4 (typically 360p / 720p) and audio-only streams download here. For 1080p+ and merged output, use Open in ytdlnis (Android).
