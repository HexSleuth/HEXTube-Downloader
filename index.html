Fixed in this build
  • Cobalt auth detection — probes now check the exact error code (error.api.auth.jwt.missing, error.api.turnstile.missing). Instances that require a key are hidden from the working list instead of failing at download time.
  • Cobalt v10 + v7 — requests try POST / first, then fall back to POST /api/json on older instances.
  • No-key fallbacks — YouTube uses Piped/Invidious only; TikTok tries TikWM before touching Cobalt. Cobalt is only used where it's really needed.
  • Graceful errors — if every Cobalt instance requires a key, you get clear guidance instead of a dead end.
