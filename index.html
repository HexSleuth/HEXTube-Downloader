Supported formats
  • Video: MP4 (H.264), WEBM — up to 4K where the source allows
  • Audio: MP3, M4A, Opus, OGG, WAV — up to 320 kbps through server-side conversion
  • Direct YouTube streams are capped by the source (~128–160 kbps audio, 360p / 720p muxed video). Use Cobalt or yt-dlp for higher bitrates and merged 1080p+.
How it works Nothing is uploaded to us. The browser calls public API instances directly: Piped / Invidious return proxied YouTube streams, Cobalt performs the multi-platform conversion and returns a direct download URL.

Unlimited & free — no account, no usage counter, no server of ours in the middle. Speed depends on the instance you point the app at. For the full format matrix (AVI, FLV, WMV, 3GP, M4V, merged 4K) use yt-dlp with ffmpeg on desktop, or the ytdlnis app on Android.
